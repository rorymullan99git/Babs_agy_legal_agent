## ASSUMPTIONS

- **Git SSL backend on Windows**: Configured `git config http.sslBackend schannel` locally because OpenSSL lacked the local Windows certificate store issuer; `schannel` uses the native Windows trust store cleanly.
- **Main branch vs feature branch**: Pushed unmodified `lawgent` to `origin/main` first and committed `ATTRIBUTION.md` and `STATUS.md` onto `feat/au-jurisdiction` so `main` stays an exact unmodified mirror of upstream until merged.
- **AU sub-jurisdiction field**: Added `default_subjurisdiction: QLD` to `Settings` and `config.yaml` alongside `default_jurisdiction: AU` so Queensland is the explicit default sub-jurisdiction while preserving two-letter ISO-style top-level jurisdiction codes in `filter_for`.
- **AGLC4 schedule short titles**: Supported schedule short titles in parenthetical single quotes after the schedule number per AGLC4 Rule 3.1.7, allowing both explicit arguments and inline extraction to format `Criminal Code Act 1899 (Qld) sch 1 ('Criminal Code') s 23`.
- **Structural pinpoint verification**: Verified upload document pages and clauses against document metadata directly when available, avoiding false negative textual string searches on bare page numbers in body prose.
- **Docling / pdfplumber fallback selection**: Docling requires full PyTorch C++ bindings; the repository environment uses `pdfplumber` (never pypdf) for resilient zero-dependency PDF parsing and `python-docx` for Word documents, correctly enforcing `lower_trust=True` and `bounding_box_claims=False` on all fallback outputs.
- **Queensland legislation live access**: Verified that `legislation.qld.gov.au` returns 200 and renders full HTML without anti-bot blocks when accessed using a descriptive User-Agent with Python truststore Windows certificate injection. In-force status is determined by URL endpoint (`/inforce/` vs `/repealed/`) rather than string matching in historical preambles.
- **Output contract validation**: Enforced the research-aid notice as a top-level blockquote banner (`> Research aid, not legal advice.`), sentence-level reference markers (`[1]`, `[Doc p. X, cl Y]`, `[UNVERIFIED]`), and explicit accounting in `## What I could not verify` section.
- **Corpus streaming constraint**: Filtered dataset stream on Hugging Face without whole-archive downloads, keeping corpus binaries git-ignored and labelling all hits as leads requiring live re-fetch.
